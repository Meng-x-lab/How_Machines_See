# 小牧奇遇记——机器是怎么识别图像的？

《小牧奇遇记——机器是怎么识别图像的？》是一个面向儿童的 AI 教育静态前端作品，用轻松、温暖、卡通化的方式介绍图像识别的基本原理，并通过互动测验帮助用户巩固理解。

项目围绕“机器如何看见世界”展开，内容包含科普讲解、视觉化互动体验，以及与图像识别和人脸合规相关的知识测验，适合课程展示、科普活动、作品集展示和静态站点部署。

## 页面内容

- 主体科普页：介绍“机器识别图像”的基本过程，保留奶油黄、儿童化、动画感的主视觉风格。
- 图像识别知识测验：围绕像素、特征、分类器、监督学习等内容设置问答互动。
- 人脸合规测验：聚焦人脸识别、人脸生成与合规边界等主题。

三个页面已经互相连通，可以从首页进入两个测验页，也可以在两个测验页之间互相跳转并返回主体页。

## 技术形式

这是一个纯静态前端项目，不依赖 React、Vue 或构建工具链。项目以原生 HTML、CSS、JavaScript 组织，适合直接托管到 GitHub Pages、Vercel 或任意静态服务器。

这种实现方式的优点是：

- 上手成本低，结构直观，适合教学作品和展示型项目。
- 部署简单，不需要额外构建步骤。
- 页面资源路径清晰，便于后续继续扩展更多互动页或素材。

## 代码风格与前端组织特点

- 以语义清晰的静态页面为主，入口明确，目录结构简单直接。
- 共享样式与页面个性样式分层处理，公共规则集中在 `assets/css/common.css`，测验页统一主题集中在 `assets/css/quiz-theme.css`。
- 保留原作品的儿童化视觉风格，同时让三个页面在导航、按钮、底部区域和色彩氛围上更统一。
- 资源路径全部使用适合部署的相对路径，避免本地绝对路径带来的线上失效问题。
- 在尽量保留原内容和主要交互的前提下，优先提升可维护性、可读性和后续扩展性。

## 运行方式

直接使用任意静态服务器即可本地预览。例如：

```powershell
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```
